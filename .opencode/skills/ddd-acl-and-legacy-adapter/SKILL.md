# Skill: DDD ACL and Legacy Adapter

## 适用场景

当任务涉及：
- 旧表兼容
- 旧接口/旧 SDK 接入
- 宽表拆分过程中的过渡设计
- 不同上下文语义翻译

## 强制规则

1. 旧模型不要直接扩散到新领域模型；优先用 ACL/Adapter 做翻译。
2. ACL 负责翻译和隔离，不负责承载核心业务规则。
3. 旧表继续保留时，要明确：
   - 哪些字段继续读
   - 哪些字段只兼容保留
   - 新字段或新表放在哪里
4. 外部协议对象、数据库对象、领域对象、DTO 必须分层转换。
5. 任何过渡结构都要标明目标归宿和收敛方向。

## 特别提醒

- `ROBOTS` 宽表兼容不等于继续把新职责往里堆
- 安全模型复用不等于跨上下文复制内部实现
