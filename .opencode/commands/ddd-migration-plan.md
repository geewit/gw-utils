请先阅读：
- @AGENTS.md
- @.opencode/rules/ddd-package-map.md

请为我指定的上下文或模块输出一个渐进式 DDD 迁移计划。

输出必须包含：

1. 当前问题摘要
2. 目标边界摘要
3. 分 3~5 个阶段的迁移步骤
4. 每阶段涉及的 package / 模块
5. 每阶段对数据库、接口、测试的影响
6. 哪些改动可以原地整理
7. 哪些改动需要 ACL/Facade/Adapter
8. 哪些改动必须最后做
9. 每阶段的验证命令

要求：
- 优先最小可交付阶段
- 默认保留现有模块物理结构
- 默认避免跨模块大规模移动文件
